## 🌱 Featured Project — AdaptLearn

An adaptive-learning web prototype exploring different ways to present educational content to students with disabilities.

Built for **HI-03 — Adaptive Learning for Students with Disabilities**.

### What it includes

- 🎯 Presentation-format selection using an epsilon-greedy bandit approach.
- 🧠 Skill-mastery estimates using Bayesian Knowledge Tracing.
- 🔊 Text-to-speech and synchronised highlighting.
- 🎙️ Dictation-based answers where browser support is available.
- 📖 A pop-up dictionary and curated learning content.
- 🐣 A digital pet and celebration effects.
- 💾 Browser-based completion tracking with `localStorage`.

### What I explored through the project

Connecting a JavaScript frontend to a FastAPI backend, integrating browser speech features, implementing adaptive-learning logic, and taking a hackathon prototype through deployment.

**Stack:** Python · FastAPI · HTML · CSS · JavaScript · Web Speech API · localStorage

[🌐 Live demo](https://adaptlearn-1mcc.onrender.com) · [💻 Source code](https://github.com/luthfan-tech/Adaptlearn)

> Prototype scope: curated lessons, limited persistence, and no clinical validation. It does not diagnose disabilities or claim proven learning outcomes.
