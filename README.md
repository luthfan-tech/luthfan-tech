## 🌱 Featured Project — AdaptLearn

### Different needs. More ways to learn.

An adaptive-learning web prototype exploring different ways to present educational content to students with disabilities.

Built for **HI-03 — Adaptive Learning for Students with Disabilities**.

| Capability | Implementation |
|---|---|
| 🎯 Format adaptation | Epsilon-greedy selection across presentation formats |
| 🧠 Mastery estimation | Bayesian Knowledge Tracing |
| 🔊 Reading support | Text-to-speech and synchronised highlighting |
| 🎙️ Alternative input | Dictation where browser support is available |
| 📖 Vocabulary support | Pop-up dictionary |
| 🐣 Motivation | Digital pet and celebration effects |
| 💾 Completion tracking | Browser `localStorage` |

**What I explored:** connecting a JavaScript frontend to FastAPI, integrating browser speech features, implementing adaptive-learning logic, and deploying a working prototype.

**Stack:** Python · FastAPI · HTML · CSS · JavaScript · Web Speech API

[🌐 Try the app](https://adaptlearn-1mcc.onrender.com) · [💻 Explore the code](https://github.com/luthfan-tech/Adaptlearn)

> Hackathon prototype: curated lessons, limited persistence, and no clinical validation. It does not diagnose disabilities or claim proven learning outcomes.
